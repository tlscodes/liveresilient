## UNCHECKED, stated plainly

- **The grown replay inputs have no bar.** Today's 38-capture, 287-row corpus
  scores 1.097412 and there is nothing to compare that to. Gate 2c asks about the
  corpus the bar was measured on, and that is what was measured. Deriving a
  threshold for the grown inputs needs a stated basis and belongs to whoever owns
  the gate.
- **`trend` is a dead lever.** Honest, not broken — its detector holds no state

  parameter combinations score one identical raw. The fix is v4 section 6 and is
  blocked on rig rows since 2026-08-11.
- **Section 5's verdict is x86_64 only.** The instrument runs from one command;
  it needs an arm64 host, not more work.
- **The recorded `signed_config` flake has not reproduced.** `tools/hunt_flake.sh`
  is time-boxed and says so: "not reproduced" is a measurement, not a clean bill
  of health.

## Decisions the code cannot explain about itself

- **Availability is a value with one member, not an interface with an empty
  implementation.** Two earlier designs were rejected in review for a reason worth
  keeping: a second named implementation that quietly delegates to ordinary
  behaviour makes a future reader conclude the capability is built and merely
  switched off. The present state is therefore unrepresentable, and adding it later
  breaks every consumer at compile time — that forced review is the mechanism.
- **Gate 4e is a rendered-output test on purpose.** A source search cannot answer
  "can this app claim the capability", because a claim can be assembled at run
  time, translated, arrive from a server document, or be made by a lock icon. The
  inversion — the surface renders what the value's translator returns — makes a
  false claim unconstructible rather than merely searchable.
- **The 2c snapshot was restored, not chosen.** The gate's own words are "the same
  corpus"; `replay_benchmark_test.dart:74` has recorded 23 captures and 272 rows
  since the gate was built; and the measured lane and atlas components landed on
  the design's own recorded 1.072 and 1.314. The objection that the subset was
  picked after seeing a failure is written into `docs/GATE_2C_REPLAY.md` rather
  than left for a reader to raise.

## Traps found the hard way today

- **A gate pinned to an ignored file is green only on the machine that wrote it.**
  `tools/suite-logs/` is in `.gitignore`; the 2c evidence had to move to
  `tools/t2/gate_2c/`, and the run logs needed `git add -f`. Record a
  measurement's inputs by NAME — mtimes do not survive a clone.
- **A source predicate must measure code, not comments.** Three of four first-run
  failures were predicates reading doc comments or treating a destructuring
  pattern as a construction. Strip comments, write the predicate positionally, and
  prove it on a synthetic counterexample in the same test.
- **A widget test must build the app's own theme.** A bare `MaterialApp` throws on
  a theme extension, which fails the test for a reason unrelated to its subject.
- **A model stop can come from the files an agent reads, not from the brief.**
  Three dispatches for the status value were stopped, the third mid-work after the
  agent had read the transport sources. Quoting what an agent needs INLINE is what
  made the presentation slice succeed first try.
